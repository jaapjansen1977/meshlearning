# Leeruitkomsten fysiotherapie

**[Download het Exceloverzicht](https://github.com/jaapjansen1977/meshlearning/raw/refs/heads/main/docs/onderwijs/leeruitkomsten.xlsx)**

Het bestand koppelt acht gekozen leeruitkomsten aan vier ontwikkellijnen en 42 indicatoren, met de oorspronkelijke formuleringen op beide ontwikkelniveaus naast elkaar.

Het bevat een filterbaar overzicht, de volledige leeruitkomsten, een dekkingsmatrix, het oorspronkelijke niveaukader en een leeswijzer. De primaire en aanvullende koppelingen zijn een toegelicht ontwerpvoorstel; de leeruitkomstzinnen en indicatoren zijn ongewijzigd overgenomen.

Je kunt ook [het bestand op GitHub openen](leeruitkomsten.xlsx) en rechtsboven **Download raw file** kiezen.
